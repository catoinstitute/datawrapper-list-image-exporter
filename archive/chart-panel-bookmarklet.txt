CATO CHART PANEL - BOOKMARKLET
==============================

Lists every Datawrapper chart on a cato.org page. Each one gets four buttons,
all the same weight - there is no way to know which one someone came for:

  16:9 image           downloads <id>-16x9.png
  16:9 plain           downloads <id>-16x9-plain.png, no title/notes/sources
  Copy ID              copies the five-character chart ID
  Open chart resizer   opens the resizer with that chart already loaded

The images are the files Datawrapper generated at publish time. They download
the moment you click - wherever your browser is set to put downloads.

A "Show plain version" link under each preview swaps it between the two, so
you can see what the plain export actually leaves out before saving it. The
resizer follows that choice: if the plain version is on screen when you click
"Open chart resizer", the resizer opens with the plain version already loaded
and its own "Show plain version" toggle flipped, so what you see in the panel
is what you get in the tool.

BEFORE YOU USE IT - SET THE RESIZER URL
---------------------------------------
The first line of the source sets where the resizer lives:

  var TOOL='http://127.0.0.1:5500/v2-bookmarklet.html';

That is a localhost address, so "Open chart resizer" only works while you have
the file being served locally. Change it to the real address once the resizer
is hosted, and rebuild the paste line (see the bottom of this file).

HOW THE DOWNLOAD WORKS
----------------------
A download attribute is ignored on a cross-origin link, so the bytes have to
be local before anything can be saved. Two routes, tried in order:

  1. fetch - hands back the published file byte for byte, exactly as
     Datawrapper optimised it. Needs connect-src to allow dwcdn, which cannot
     be verified from outside cato.org.
  2. <img> into a canvas - only needs img-src, which the page already grants
     dwcdn for its print fallback, so it works wherever the preview works.
     Re-encoding inflates the PNG by about a third (160KB becomes 218KB on a
     typical chart) because the canvas encoder does not optimise the way
     Datawrapper does. Same pixels, bigger file.

If both fail the button opens the image in a tab instead of failing silently.

Either route keeps the chart ID in the filename. Right-click and Save Image As
would not - that names every chart on the page website.png, so three charts
become website.png, website(1).png and website(2).png.

Saving several charts in a row may make Chrome ask whether to allow multiple
downloads. That is browser behaviour for any scripted download; click Allow
once for the site.

THE PREVIEW IS THE CHECK
------------------------
Each chart's preview image is website.png itself - the exact file the first
button saves. So the preview doubles as the test: if it renders, the export
exists and the buttons work. If it fails to load, the chart was published
before the website export presets were configured. The panel then hides the
broken image and its toggle, turns the three export-dependent buttons neutral
and inert, and shows a single line - "Republish this chart to generate its
16:9 image" - linking to that chart's Publish screen, with an arrow marking
that the link leaves the page. Copy ID keeps working, because the ID exists
whether or not the export does.

Once a preview has loaded successfully that verdict is settled, so a later
failure is treated as a failed swap - it reverts to the full image rather than
re-running the missing-export path and counting the chart twice.

When any chart is affected, the count appears once under the header - "2 of 3
charts do not have a 16:9 image yet. Republish in Datawrapper using the links
below to generate images." - rather than repeating the explanation on every
card. It points at the per-card links rather than carrying its own.

Both presets are written by the same publish, so a missing website.png means
website-plain.png is missing too - one signal covers every export button.

        im2.crossOrigin='anonymous';
        im2.onload=function(){
          var cv=document.createElement('canvas');
          cv.width=im2.naturalWidth;
          cv.height=im2.naturalHeight;
          cv.getContext('2d').drawImage(im2,0,0);
          cv.toBlob(give,'image/png');
        };
        /* Last resort: the file is still reachable, so hand it over the old
           way rather than failing silently. */
        im2.onerror=function(){
          btn.textContent=label;
          window.open(url,'_blank','noopener');
        };
        im2.src=url;
      });
    }

    var row=el('div','display:flex;align-items:center;flex-wrap:wrap;gap:6px');

    var full=el('button',BTN,'16:9 image');
    full.title='Download website.png';
    full.onclick=function(){saveImage('website.png','-16x9',full);};

    var plain=el('button',BTN,'16:9 plain');
    plain.title='Download website-plain.png, without title, notes or sources';
    plain.onclick=function(){saveImage('website-plain.png','-16x9-plain',plain);};

    var copy=el('button',BTN,'Copy ID');
    copy.title='Copy '+c.id+' to the clipboard';
    copy.onclick=function(){
      navigator.clipboard.writeText(c.id).then(function(){
        copy.textContent='Copied '+c.id;
        setTimeout(function(){copy.textContent='Copy ID';},1400);
      });
    };

    /* Built at click time, not bound up front, so it follows the preview:
       whatever version is on screen is the one the resizer opens. The tool
       reads ?plain=1 and opens with the plain version already loaded. */
    var resize=el('button',BTN,'Open chart resizer');
    resize.title='Open the version shown above in the resizer, to crop it';
    resize.onclick=function(){
      window.open(TOOL+'?id='+c.id+(showing==='plain'?'&plain=1':''),'_blank','noopener');
    };

    row.appendChild(full);row.appendChild(plain);row.appendChild(copy);row.appendChild(resize);

    /* Neutral, not a faded primary: the strongest colour on a card should
       never belong to a control that does nothing. Copy ID keeps working
       because the ID exists whether or not the export does. */
    function disable(btn){
      btn.style.cssText=BTN_OFF;
      btn.title='Not available yet - this chart needs republishing';
      btn.onclick=function(){};
    }

    /* Both presets are written by the same publish, so a missing website.png
       means website-plain.png is missing too - and the resizer has nothing to
       load either. */
    /* Once the first load succeeds the verdict is settled, so a later failure
       is a failed swap, not a missing export: fall back to the full image
       rather than re-running the missing-export path and double-counting. */
    var settled=false;
    im.onload=function(){settled=true;};
    im.onerror=function(){
      if(settled){
        showing='full';
        toggle.textContent='Show plain version';
        im.src=CDN+c.id+'/website.png';
        return;
      }
      toggle.style.display='none';
      im.style.display='none';
      disable(full);disable(plain);disable(resize);
      /* The summary above already says a chart is missing its image, so this
         line is only the action. The arrow sits inside the link so it is part
         of what gets underlined, and warns that the click leaves the page. */
      var a=el('a',null,'Republish this chart');
      a.href='https://app.datawrapper.de/chart/'+c.id+'/publish';
      a.target='_blank';a.rel='noopener';
      a.style.cssText='color:#856404;font-weight:700';
      a.insertAdjacentHTML('beforeend','<svg width="11" height="11" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true" style="display:inline-block;vertical-align:-1px;margin-left:4px"><path d="M18 13v6a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h6"/><polyline points="15 3 21 3 21 9"/><line x1="10" y1="14" x2="21" y2="3"/></svg>');
      note.appendChild(a);
      note.appendChild(document.createTextNode(' to generate its 16:9 image.'));
      note.style.display='block';
      countMissing();
    };

    item.appendChild(im);item.appendChild(toggle);item.appendChild(row);item.appendChild(note);
    p.appendChild(item);
    if(i<charts.length-1){
      p.appendChild(el('hr','border:0;border-top:1px solid '+RULE+';margin:20px 0'));
    }
  });

  /* Escape closes it, the way every other overlay does. */
  function onKey(e){
    if(e.key==='Escape'){p.remove();document.removeEventListener('keydown',onKey);}
  }
  document.addEventListener('keydown',onKey);

  document.body.appendChild(p);
})()
